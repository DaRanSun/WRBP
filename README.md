# WRBP · 英雄联盟手游竞技征召模拟

用 WRPedia 的英雄池，按 WROB 的“赛事征召”规则模拟 BP，可以开全局 BP。不计时。两个版本：

| | 单机版 | 联机版 |
| --- | --- | --- |
| 地址 | <https://wrbp.netlify.app> | <https://wrbp.wrbp.workers.dev> |
| 用法 | 一个人填双方的 BP | 建房后发链接：双端（双方教练）或三端（双方教练 + 裁判），可以加任意多个观战 |
| 托管 | Netlify（纯静态） | Cloudflare Workers + Durable Objects（一个房间一个对象，WebSocket 实时同步） |
| 进度存在哪 | 本机浏览器 | 服务器上的房间里（14 天没人操作自动删除） |

手机浏览器打开后可以“添加到主屏幕”（iOS Safari 在分享菜单里，安卓 Chrome 在右上角菜单里），之后像 App 一样全屏打开。

## 规则

**竞技征召**（照 WROB `config/draft.yaml` 的 `tournament`）：

| 阶段 | 顺序 |
| --- | --- |
| 第一轮禁用 | 蓝 红 蓝 红 蓝 红 |
| 第一轮选用 | 蓝 红红 蓝蓝 红 |
| 第二轮禁用 | 红 蓝 红 蓝 |
| 第二轮选用 | 红 蓝蓝 红 |

- 双方各禁 5 个、选 5 个，不计时。
- 同一局里禁用或选用过的英雄，双方都不能再用。
- 禁用位可以空 Ban。

**全局 BP**（照 WROB 的无畏征召）：

- **双边**：之前任何一方选过的英雄，双方都不能再选，也不能再禁。
- **仅本队**：只锁本队之前选过的，对面照样能选，禁用不受限。
- **不启用**：每局独立。

之前禁用过的英雄不会被锁。这一局已经填了的英雄如果在新模式下会被锁，就不能切换模式，要先改掉或重开本局。

**系列赛**：BO1 / BO3 / BO5 / BO7。BP 完成后记下胜方，下一局默认败方在蓝方；这一局还没开始时可以换边。有一方拿到赛点，系列赛就结束；想接着打，可以把赛制改大。

## 单机版操作

- **点选**：点英雄池里的英雄，填进当前这一手。灰色的不能选，角标写着原因：“禁”是本局已禁，“蓝 / 红”是本局已选，“G1”是全局 BP 第 1 局用过。鼠标停在上面能看到完整原因、称号和 WRL 选禁次数。
- **搜索**：国服名、称号、昵称、英文名、WRPedia 的繁中原名、拼音、首字母都能搜（剑魔、jm、厄薩斯、Aatrox 都是亚托克斯）。完全匹配的排最前，回车选第一个能选的（带“回车”标记的那个）。不在输入框时直接打字就会进搜索框，`/` 也能聚焦。所以可以“打字、回车、打字、回车”一路填下去。
- **回头改**：点两侧任意一格，或者点流程条上的任意一手，下一个选的英雄就填进那一格。状态栏有“清空这一格”“取消修改”，`Esc` 也能取消。清空之后，当前手会回到最早的空格。
- **撤销 / 重做**：`Ctrl / ⌘ + Z`、`Ctrl / ⌘ + Shift + Z`，顶栏也有按钮。记胜方、重开本局、新系列赛都能撤销。
- **队名**：直接点两侧的队名改。队名跟着队伍走，换边时一起换。
- **排序**：按名称（拼音），或者按 WRL 热度（已录入比赛里的选用加禁用次数）。
- **复制文字记录**：系列赛记录右上角，把每局双方的选用和禁用复制成文字。

进度存在本机浏览器里，刷新或关掉再开都还在。换浏览器、开隐私模式或清了网站数据，就从新的系列赛开始。

## 联机版

**建房**：打开联机版首页，选模式、填队名、选赛制和全局 BP，点“创建房间”，得到几条链接：

| 链接 | 给谁 | 能做什么 |
| --- | --- | --- |
| 裁判（只有三端） | 自己留着 | 改任意一格、替某一方锁定、撤销、记胜负、换边、改赛制和全局 BP、重开、新系列赛 |
| 队伍 A 教练 / 队伍 B 教练 | 对应的教练 | 轮到自己时预选、锁定、空 Ban；改自己的队名；双端里发起需要对方同意的操作 |
| 观战 | 谁都可以 | 只能看；也能当 OBS 浏览器源 |

链接里带着身份口令：拿到教练链接的人就能替这一队 BP，只发给对应的人。同一个链接可以在几台设备上同时开。建过的房间记在本机的联机首页上，可以回头再拿链接。

**教练怎么 BP**：轮到自己时，点英雄（或搜索后回车）是**预选**，所有人都看得到，在格子里半透明显示；再点“锁定”（或搜索框空着时按回车）才算数。没轮到时点英雄会提示现在轮到谁。轮到自己时手机会震一下，浏览器标签页标题前面会出现“【轮到你】”。

**需要权限的操作**（撤销、记胜负、换边、改赛制和全局 BP、重开本局、新系列赛）：

- **三端**：裁判直接做，教练做不了。
- **双端**：教练发起请求（按钮后面带“…”），对方在页面顶部点“同意”才执行。请求发出后 BP 又往下走了，请求自动作废。
- **不用对方同意的两种情况**：记对方胜（认输），以及上一局输的一方在下一局开始 BP 之前换边（败方选边）。

**页面上还有**：顶部是房间号、你的身份、连接状态和各方在不在线；状态栏上方一行写着最近一次操作；“链接”按钮可以再拿链接（裁判拿得到所有链接，教练只拿得到自己的和观战的）。断线会自动重连，手机切回前台时会先确认连接还在。

## 更新英雄池

英雄资料、国服名和昵称、头像与立绘都从 WRPedia 复制过来，所以 WRBP 可以单独打开或发布。WRPedia 加了新英雄、改了昵称或录入了新比赛后，重跑：

```bash
node tools/sync-wrpedia.js              # 默认读 ../WRPedia
node tools/sync-wrpedia.js 路径/WRPedia
```

它会重新生成 `data/champions.js`，同步 `assets/champions/`，并删掉 WRPedia 里已经没有的旧图。个别英雄的图片处理和 WROB 的 `config/art.yaml` 一致：诺拉没有方形小图，用立绘裁；彗的原画是横版，按焦点裁。同步之后两个版本都要重新发布（联机服务端也用英雄表校验英雄）。

## 开发和发布

第一次先装依赖（只有 wrangler，装在项目里）：

```bash
npm install
```

| 命令 | 做什么 |
| --- | --- |
| `npm run dev` | 本地跑联机版：<http://127.0.0.1:8787>（本机模拟 Workers 和 Durable Objects，不需要登录 Cloudflare） |
| `npm run check` | BP 规则和房间规则自检 |
| `node tools/check-online.mjs [地址]` | 联机端到端自检：真的建房、开两队教练 / 裁判 / 观战几个连接走一遍。不给地址就测本地 `npm run dev` |
| `npm run deploy` | 发布联机版到 Cloudflare（先 `npx wrangler login` 登录一次） |
| `npm run deploy:netlify` | 发布单机版到 Netlify |

两个版本共用同一份页面和规则：`tools/build.js` 决定各发哪些文件（Netlify 只发单机页，Cloudflare 发全部），`assets/js/site.js` 记着两个版本的地址，单机页的“联机 BP”入口据此跳转。

**Netlify**：站点 `wrbp`（团队 `daransun`），站点 ID 在 `.netlify/state.json`。发布脚本用 Netlify CLI 登录过留下的凭据（或环境变量 `NETLIFY_AUTH_TOKEN`），只上传 Netlify 上还没有的文件，和 WRPedia 录入后台的“发布公网”是同一套做法。注意：这个团队新建的站点默认开着“Netlify 团队登录”访问保护（站点的 `sso_login`），没关的时候外人打开是 401。

**Cloudflare**：Worker 名 `wrbp`，配置在 `wrangler.jsonc`。Durable Objects 用 SQLite 存储（免费套餐只支持这种）。房间状态存在房间对象里，每次变化存盘并推给房间里所有连接；连接用休眠 API，没人操作时不计费。`*.workers.dev` 在中国大陆访问不稳定，大陆的人要用的话，需要给 Worker 绑一个自己的域名。

## 目录

```text
WRBP/
├─ index.html            单机版
├─ online.html           联机首页：建房、我建过的房间、按房间号观战
├─ room.html             联机房间（教练、裁判、观战同一个页面）
├─ manifest.webmanifest  “添加到主屏幕”用的名称、图标、全屏显示
├─ assets/
│  ├─ css/wrbp.css
│  ├─ js/draft.js        BP 规则：顺序、本局去重、全局 BP、系列赛（不碰页面；浏览器、Worker、Node 共用）
│  ├─ js/champions.js    英雄检索和出图
│  ├─ js/board.js        棋盘：两侧格子、流程条、英雄池、系列赛记录（单机和联机共用）
│  ├─ js/app.js          单机版
│  ├─ js/lobby.js        联机首页
│  ├─ js/room.js         联机房间：WebSocket、预选和锁定、请求和同意
│  ├─ js/site.js         两个版本的地址
│  ├─ icons/             网站和主屏幕图标（icon.svg 是源文件，PNG 由它渲染）
│  └─ champions/         头像和立绘（同步生成）
├─ data/champions.js     英雄池（同步生成，不要手改）
├─ worker/
│  ├─ index.mjs          Worker 入口和房间对象（Durable Object）：建房、WebSocket、存盘、在线人数、过期删除
│  └─ room-logic.mjs     房间规则：身份和权限、预选和锁定、双端请求、撤销（纯函数）
├─ wrangler.jsonc        Cloudflare 配置
└─ tools/
   ├─ sync-wrpedia.js    从 WRPedia 同步英雄池
   ├─ build.js           生成 dist/，定两个版本各发哪些文件
   ├─ deploy-netlify.js  发布单机版到 Netlify
   ├─ check-draft.js     BP 规则自检
   ├─ check-room.mjs     房间规则自检
   └─ check-online.mjs   联机端到端自检
```
